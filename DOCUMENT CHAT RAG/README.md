# Chat with your docs — local Llama 3.3 RAG

A small Streamlit app that runs RAG fully locally: documents are embedded and
retrieved with FAISS, answers are generated by Llama 3.3 served by [Ollama](https://ollama.com).

## Run

```bash
ollama pull llama3.1:8b
ollama pull nomic-embed-text
pip install -r requirements.txt
streamlit run app.py
```

> Llama 3.3 only ships as a 70B model (~43 GB, needs ~48 GB RAM). On a 32 GB
> machine use `llama3.1:8b` (set in the sidebar). Models are stored in
> `OLLAMA_MODELS` (here: `D:\ollama\models`).

Upload PDF/TXT/MD files in the sidebar, click **Process documents**, then chat.

The answer is grounded in the uploaded files only and cites the source file names.
