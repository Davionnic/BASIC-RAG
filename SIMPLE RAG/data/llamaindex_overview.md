# LlamaIndex and Retrieval-Augmented Generation (RAG)

## What is Retrieval-Augmented Generation?

Retrieval-Augmented Generation (RAG) is a technique that improves the answers of a
large language model (LLM) by giving it relevant information retrieved from an
external knowledge base at query time. Instead of relying only on what the model
memorized during training, a RAG system first retrieves passages that are relevant
to the user's question and then asks the LLM to generate an answer grounded in
those passages. This reduces hallucinations and lets the model answer questions
about private or recent data it was never trained on.

A typical RAG pipeline has five stages:

1. **Loading** - read raw documents (PDFs, Markdown, web pages, databases) into memory.
2. **Chunking** - split documents into smaller nodes so they fit the model context.
3. **Embedding** - convert each chunk into a numeric vector that captures meaning.
4. **Indexing & Retrieval** - store the vectors and find the closest ones to a query.
5. **Generation** - feed the retrieved chunks plus the question to the LLM.

## What is LlamaIndex?

LlamaIndex is an open-source data framework for building LLM applications over your
own data. It provides building blocks for every stage of a RAG pipeline:

- **Readers** such as `SimpleDirectoryReader` load files from disk.
- **Node parsers** split documents into chunks called nodes.
- **Embedding models** turn nodes into vectors.
- **Indexes** like `VectorStoreIndex` organize nodes for fast retrieval.
- **Query engines** combine a retriever and an LLM to answer questions.

LlamaIndex supports persisting an index to disk so you do not have to re-embed your
documents every time the application starts.

## What is Ollama?

Ollama is a tool for running large language models locally on your own machine.
It exposes a simple HTTP API on port 11434 and supports many open models such as
Llama, Gemma, Mistral, and Phi. Because inference happens locally, your data never
leaves your computer, which is useful for privacy-sensitive applications.

In this project the chat model `gemma3:4b` is used for generation and the
`nomic-embed-text` model is used to create embeddings. Both run through Ollama.

## Why combine LlamaIndex with Ollama?

Pairing LlamaIndex with Ollama gives you a fully local RAG system: documents are
embedded and indexed on your machine, and answers are generated by a local LLM.
There are no API keys and no per-token costs. This makes it an excellent setup for
learning, prototyping, and working with confidential documents.
